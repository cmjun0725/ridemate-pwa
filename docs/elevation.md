# 고도 계산 v2

새로 계산하는 추천·직접 입력 경로에 적용됩니다. 원천은 기존 ORS 자전거 경로의 3차원 좌표이며 별도 실측 데이터로 교체한 것은 아닙니다.

- 경로 누적 거리를 기준으로 25m 간격 선형 재표본화(최대 약 12,000 구간).
- 내부 표본 3점 중앙값 필터로 단발성 요철 완화. 시작·종료 높이 보존.
- 누적 상승은 기준 높이에서 3m 이상 변화할 때 합산하고 끝 잔차 포함. 작은 지형 변화도 일부 제거될 수 있는 추정 정책입니다.
- 업힐과 총상승은 같은 보정 표본을 사용. 업힐의 평균 경사는 시작·종료 순상승/거리로 계산하며 최소 2.2%, 180m, 순상승 8m 조건 적용.
- 그래프는 최대 120점, 구간별 최저·최고와 양끝 보존. 최소 세로축 범위 30m.
- 누락·비정상 높이는 0m로 치환하지 않고 경로 계산 실패로 처리.

기존 저장 코스는 자동 재작성하지 않습니다. 새 경로 계산부터 수치가 달라집니다. 교량·터널 및 지표면과 실제 노면의 차이는 이 처리만으로 해결할 수 없으며, 화면에 추정치 안내를 표시합니다.

테스트는 합성 고도의 상승/하강, 좌표 밀도 차이, 평지 잡음, 결측치, 중복 좌표를 검증합니다. 실측 대비 오차율 개선은 아직 검증하지 않았습니다.
